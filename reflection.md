# Reflection

One of the challenges I encountered during the setup was working with Django’s project structure. At first, I felt overwhelmed by the different files and their purposes, especially when handling settings and app configurations. I sometimes placed code in the wrong file or forgot to register apps in INSTALLED_APPS, which caused errors I didn’t immediately understand. To overcome this, I made it a habit to revisit the Django documentation and watch short tutorials that explained the role of each file in a project. This gave me a clearer picture of how everything is connected.

I also had some struggles with Git when collaborating across different machines. I ran into issues with merge conflicts because I didn’t always pull the latest changes before pushing my own updates. Eventually, I learned to use git pull regularly and practiced resolving conflicts by reviewing differences carefully with git diff. Although it was stressful at first, these experiences helped me become more comfortable with version control. Overall, these challenges taught me that consistent practice, reading documentation, and patience are key to improving in both Django development and Git management.
